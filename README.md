# Kodeance Homebrew tap

```bash
brew install --cask kodeance/tap/monnercode
```

| Cask | |
|---|---|
| `monnercode` | Monnercode (formerly Sicode) — macOS worktree terminal for coding agents ([releases](https://github.com/Kodeance/monnercode-releases)) |

The `sicode` cask is renamed to `monnercode` from the first Monnercode release on; `brew` moves existing installs over.
